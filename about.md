# AutoDeafen for Linux

Deafens you on Discord when a run gets far enough, and undeafens you when you
die, finish, restart or quit. Made for Geometry Dash through Proton, including
pure Wayland sessions. It uses **no keybinds and no Discord plugin**.

Set it up from the button in the pause menu.

**This mod was written by AI (Claude).** It is not related to Lynxdeer's
AutoDeafen or snytex's AutoDeafen-Linux.
